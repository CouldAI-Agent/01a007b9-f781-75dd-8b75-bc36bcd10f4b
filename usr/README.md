# Mr. Sound

Mr. Sound is a relaxing ambient noise and soundboard application built with Flutter. It provides a clean, responsive interface to mix and match various environmental sounds to help you focus, relax, or sleep.

## Features
- **Responsive Sound Grid:** Adapts beautifully across mobile, tablet, and desktop screens.
- **Ambient Categories:** Includes sounds like Rain, Waves, Forest, Fire, Wind, and more.
- **Toggle Playback:** Visual feedback when sounds are active (audio playback can be integrated).
- **Dark Theme:** A soothing dark interface suitable for night-time use.

## Tech Stack
- Flutter (Dart)
- Material 3 Design

## Setup
1. Ensure Flutter is installed.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to launch the app on your preferred device.
